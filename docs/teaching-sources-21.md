# Teaching source audit: cases 021–030

Verified with browser research on 2026-09-20. This document audits the new history cards in `src/lib/learning/lessons-21.ts`. The existing case files remain the source of the starting facts, option IDs, research IDs, and authored halfway events.

Choice scores are authored coaching judgments, in five-point steps. They use the case's decision-time evidence, not historical agreement or a player's writing length. They are not predicted success rates. Practice questions change a condition explicitly and describe possible choices; they do not claim those conditions happened. Event revisions use only the existing authored event and offer a concrete response. Historical results stay in the history fields.

- Case 021's `c21-r1` through `c21-r4` and `own/license/partner/hold` IDs were checked against `batch-13.ts`; cases 022–030 were checked by importing `batch-22.ts`.
- Runtime assertion checks cover ID matching, bounds and five-point score steps, event option existence, word limits, and practice answer references. TypeScript validation is limited to this content module and its type contract; root integration and browser receipts are separate.
